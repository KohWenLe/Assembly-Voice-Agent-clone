# Work tracking during requirements discovery

Discovery decisions and open questions are tracked locally in [the requirements document](../product/requirements.md). This is the current discovery convention; implementation ticketing has not yet been selected.

The repository's existing origin is https://github.com/KohWenLe/Assembly-Voice-Agent-clone.git. No external issues or labels have been created or changed as part of requirements discovery.

When implementation work is decomposed, select its tracker using the existing repository context and the team's preferences. Do not interpret draft recommendations as accepted tickets.
